# Project Reflection

## What did you ask Copilot to help you build? How did you break down the problem?

I asked GitHub Copilot to help me build a basic To-Do List web application using Python and Flask. I broke the project down into smaller features instead of asking Copilot to create the entire application at once. First, I asked it to create the basic Flask structure and homepage. Then I asked it to add the ability to enter and add tasks. After that, I asked it to add a feature for marking tasks as complete. I tested each feature before moving on to the next one.

## How did your approach to asking questions change as you worked?

At first, my prompts were focused on creating the basic structure of the application. As I worked, I learned that it was better to give Copilot more specific instructions about one feature at a time. Instead of asking for the entire application, I asked for individual features and explained what I wanted each feature to do. This made it easier to understand the code and test each part of the application.

## What parts of the development process with GitHub Copilot surprised you?

I was surprised by how quickly Copilot could create working code from a short description of what I wanted. I also learned that Copilot's suggestions do not always automatically appear in my local project. At one point, I had to use `git pull origin main` to get changes into my local files. This showed me that I still needed to understand Git and how changes move between GitHub and my computer.

## What did you learn about the technology you used that you didn't know before?

I learned more about how Flask connects Python code to webpages. I learned that routes can be used to control what happens when a user visits a page or submits a form. I also learned how HTML forms can send information to Flask and how Flask can use that information to update the webpage. Before this project, I had not worked as much with how a Python program could be used to create an interactive web application.

## What would you do differently if you had to build this again?

If I built this application again, I would plan the features and file structure before starting. I would also become more familiar with Git commands so I would better understand when I need to pull changes from GitHub or push changes to the repository. I would probably add more features, such as deleting tasks, saving tasks permanently, and improving the design. I would continue using Copilot for assistance, but I would try to understand each suggested change before accepting it.
